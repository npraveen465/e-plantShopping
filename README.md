# e-plantShopping

**e-plantShopping** is an online e-commerce web application designed for plant enthusiasts to browse, select, and purchase various houseplants and gardening products.

## Overview

This React-based application provides an intuitive shopping experience featuring:
- A landing page introducing the plant shop.
- A product listing page categorized by plant types (e.g., Air Purifying, Aromatic).
- Interactive shopping cart management to add, increase, decrease, or remove plant items.
- Real-time calculation of total quantities and pricing.

## Features

- **Product Catalog:** View plants with images, descriptions, and prices.
- **Shopping Cart:** Add plants to your cart, update quantities, and view cart totals.
- **Responsive Layout:** Designed for smooth user experience across devices.

## Tech Stack

- **Frontend:** React, HTML5, CSS3, JavaScript (ES6+)
- **Build Tool:** Vite
